      Blocked sites

      A domain blocks itself and its subdomains, on http and https. Foxleash refuses a blocked site even if you approved it. Blank lines are ignored. The built-in list is short and names mostly sites in the United States, the Nordic countries and the United Kingdom: a site that is not on it is not blocked until you add it.

        Agent windows

        Foxleash opens an agent session's first tab in a new window beside yours, and the agent's later tabs in that window too, so the tab selected in your window stays as it is. Firefox may bring that window to the front when it opens it, and a page in it that asks you something, such as whether to allow a site, brings that window to the front if your desktop allows it. When the session ends, Foxleash closes that window if it holds only blank tabs and is not your last window. A session that already has tabs keeps them where they are.

        Recipes

        A recipe is a task's steps written down, with the sites it uses. You write, edit and delete recipes here, and Foxleash keeps them on this computer. An agent can also propose a recipe, which Foxleash saves only when you click Save on the page it opens. An agent can read your saved recipes when it asks.
