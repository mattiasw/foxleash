      Blocked sites

        Recipes

        A recipe is a task's steps written down, with the sites it uses. You write, edit and delete recipes here, and Foxhand keeps them on this computer. An agent can also propose a recipe, which Foxhand saves only when you click Save on the page it opens. An agent can read your saved recipes when it asks.
