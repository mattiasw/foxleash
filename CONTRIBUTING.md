# Contributing

Foxleash is licensed under the GNU General Public License, version 3 or later
(GPL-3.0-or-later); see [LICENSE](LICENSE). A contribution you submit is licensed under the same
license. There is no contributor license agreement and no sign-off to add.

Submit only work that you have the right to license that way. Code copied from another project
follows the "Borrowed code" section of [AGENTS.md](AGENTS.md).

- [docs/development.md](docs/development.md) describes how to build, check and test Foxleash.
- [AGENTS.md](AGENTS.md) describes the project's conventions.

Report a security problem as [SECURITY.md](SECURITY.md) describes, not in an issue.
